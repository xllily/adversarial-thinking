# Changelog

## 0.1.1 - 2026-09-07

Experimental release. The current evaluation evidence does not establish causal Skill uplift.

- Added bilingual discovery pages, a compact `llms.txt` index, and reviewable GitHub metadata while keeping `SKILL.md` as the sole behavioral authority.
- Added a positive calibration invariant: decision quality over disagreement, symmetric evidence standards, valid no-change outcomes, and an explicit return to the host workflow.
- Narrowed automatic discovery toward material, consequential, or hard-to-reverse decisions and away from routine, reversible, well-tested work.
- Added behavioral specifications for a supported consequential plan and an unnamed low-risk automatic-invocation negative case.
- Added frozen T0/T1 evaluation infrastructure, restricted Docker tool isolation, and an opt-in explicit Review diagnostic profile with pinned local token accounting and failure-stop coverage.
- Recorded GLM and native Kilo diagnostics with their evidence limits. Native C1/C3 observations do not demonstrate a C3 advantage; the C3 candidate is not applied to the released Skill.
- Kept private run data and local planning separate from public reports. Local validation does not establish hosted tokenizer parity, actual billing, or strict behavioral acceptance.

## 0.1.0 - 2026-08-31

- Published the first experimental Agent Skills package.
- Included Review, Brainstorm, Plan, and Exec branches with progressive disclosure.
- Included 34 behavioral specifications.
- Recorded an 18-run retrospective paired smoke campaign; the nominal baseline was not isolated from the installed skill, so no comparative conclusion is supported.
