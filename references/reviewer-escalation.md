# Reviewer Escalation

## Isolated or diverse critic

A fresh context without prior diagnoses or an expected verdict provides context isolation. A different model provides model diversity. These are distinct and neither guarantees uncorrelated judgment.

- Keep the critic read-only and sandboxed when available.
- Send the smallest sufficient artifact, contract, and evidence. Omit other diagnoses and expected verdicts.
- Ask only for material failures, impact, and corrections; explicitly allow no findings.
- Disclose fresh versus inherited context and same versus different model. Call a pass independent only to the degree the host can substantiate.

## Panel and synthesis

Use a panel only when a high-impact decision retains a consequential dispute after evidence checking, distinct reviewers can inspect different evidence or lenses likely to change the outcome, and host capability and authorization make the cost proportionate. Multiple plausible options alone do not justify a panel.

Run separate fresh-context passes before reviewers see one another's conclusions. Debate only disputed evidence. A synthesizer must verify the source claims and decide what survives; reviewer agreement is not evidence. Stop after two rounds or any round adding no new evidence, then surface the unresolved decision.

Do not invoke an external service, expose data, or incur cost beyond the host's approval model. If an optional critic is unavailable, continue with the core checkpoint and state the limitation; never fabricate a second opinion.
